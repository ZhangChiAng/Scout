# 模型与采集器接入交接

供后续 agent 审计和接手使用。此处保存接入决策与验证边界，运行参数以配置和源码为准。

## 接入决策

- 官方 Codex SDK 使用 Scout 专用认证目录，模型由 models.toml 配置。
  专用目录禁止 config.toml，避免继承日常 Codex 的端点、MCP 或其他能力配置。
  修改认证逻辑时保留目录隔离，不使用正式账户注销来构造失败场景。
- 模型请求默认禁用执行和联网能力；知乎搜索词提取例外启用实时搜索及所需宿主。
  此例外用于核实名称和概念，不应扩展到内容评价或偏好归纳。
- 预览的只读保证针对业务 SQLite 和飞书；SDK 仍可能更新专用目录中的认证、缓存和状态。
- 采集器独立管理知乎会话，Scout 通过本机鉴权 HTTP 访问；Cookie 留在采集器会话目录，
  不进入 Scout 配置、模型输入或交接文档。账户导入成功不代表搜索与正文采集已通过。
- 2026-10-03 用户要求全项目统一使用 `gpt-6.1-sol`，移除旧模型配置。
  保留 `[model]` 的 `medium` 和 `[zhihu_content]` 的 `low`，不另设提词模型节。
  历史调用记录保留实际模型身份，不回写为新模型；此条记录用户决策，不作为调用验收证据。

## 本地产物与脱敏

知乎 CLI 及后台扫描会导出本地运行产物；新流程只导出 schema 5 的单次评价记录。
扫描产物可能包含话题、内容与任务信息，应留在已忽略的本地数据目录，
不得复制到 handoff 或作为仓库验收附件；自定义路径时须检查忽略规则。

交接只保留必要结论。不得保存实际凭据、Cookie、个人偏好与反馈原文、账户与群标识、
消息与任务标识、本机绝对路径或原始模型响应。必要位置使用环境变量名、相对路径或占位符。

## 事实来源与验证边界

接入规则来自精简前 README，并核对了 codex_runtime 和知乎 CLI 的相关入口。
上述接入规则最初整理时未进行登录、模型、采集器或飞书实测；不能把旧文档或历史报告当作当前验证证据。
接入变更需验证真实登录、刷新、重启后的认证复用及受影响的模型和采集链路；
涉及投递时完成真实飞书验收，未覆盖场景在回复中说明，不生成独立验收文件。
